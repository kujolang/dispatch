The existing runner, run lock, immutable control journal and source-bound recovery
projection remain authority. Add an opt-in static policy to the anchored workflow:
closed predicates over finalized Eval/human/node receipts; immutable branch activation;
one-level disjoint node groups with explicit terminal decisions; a monotonic ceiling
on durable program dispatches. No expressions, topology edits, loops or new node kinds.

Branch activation and subgraph finalization are separate operator-authorized locked
operations, never implicit resume. Unselected nodes remain pending with a graph-local
not_selected explanation, not successful/cancelled. A conditional join omits only
proven inactive dependencies and retains exact activation identities. Parent consumers
bind the subgraph receipt; internal facts without that receipt cannot satisfy it.

Failure action is separate from terminal truth: fail, block, optional continuation,
route through a declared branch, or require a declared authorized review. Routing a
failure preserves that failure and makes selected remediation independently required.
Budgets count dispatch reservations, not process success or guessed token/cost use.
Exhaustion blocks new dispatch; existing consumed work remains resolvable.

Same-node retries remain deferred: current bound consumers use immutable attempt 1
and permanent one-use claims. A new attempt/rebinding/retirement contract is required
before adding a retry ceiling. A repair node is a different declared execution, never
a replay exception for uncertainty. This decision preserves scope permitted by Part 12.
